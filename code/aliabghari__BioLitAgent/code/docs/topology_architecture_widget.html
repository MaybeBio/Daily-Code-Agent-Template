BioLitAgent System Topology

Autonomous Bioprocess Literature & Regulatory Monitoring • HITL Governance • Word Digest

1. Ingestion Tier Parallel
literature_scout.py REST + MCP

Queries PubMed & bioRxiv, deduplicates PMIDs, generates 2-3 sentence syntheses.

PubMed / bioRxiv HTTP 200
regulatory_watch.py Playwright

Monitors FDA, EMA & ICH index pages. Triggers Gemini on SHA-256 hash delta.

FDA / EMA / ICH 4 Sources
pdf_ingestion.py PyMuPDF

Polls inbox/ for new PDFs/patents, extracts text, archives to inbox/processed/.

inbox/*.pdf Archival Flow
Gemini 2.5 Flash & Cache Central Config

Model standardized in model_config.py. Dry-run cache prevents quota consumption.

Staging Buffer JSONL
pending_items.jsonl Staging Queue

Decoupled FIFO staging buffer where all Phase 1 scouts append candidate records conforming to a unified 13-field schema.

• id (UUIDv4)
• source_type: literature | regulatory
• content_hash (SHA-256)
• url_unknown / date_unknown
• description (Original paraphrase)
Human Review Gate ➔ Phase 2
